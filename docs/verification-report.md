# Verification Report — PWM Signal Analyser

## Overview

This document collects the evidence generated by the verification activities for the PWM Signal Analyser design. Each test is referenced against the corresponding requirement from the [specification](specification.md), the test outcome is recorded, and the relevance of each test is explained.

Verification was performed using [cocotb](https://www.cocotb.org/) v2.0.1 with Verilator v5.048 (2026-04-26) as the simulation backend. The testbench instantiates the top-level module `tt_um_PaulineKreis_PWM_Analyser` via `tb.v`.

---

### V8 — Multiplexed Display Control

**Requirements covered:** [R8 — Multiplexed Display Control](specification.md#r8--multiplexed-display-control)

**Test:** All tests (implicitly)

**Relevance:** The `read_display` helper function used in all tests reads `o_digit_en` (4-bit multiplexed digit enable) alongside `o_seg` to decode display output. Correct decoding across all tests implicitly confirms that time-multiplexed digit activation is functioning correctly. No dedicated standalone test was written for this requirement; it is exercised as a prerequisite for every display readout.

### V10 — Modular Design Structure

**Requirements covered:** [R10 — Modular Design Structure](specification.md#r10--modular-design-structure)

**Status:** Verified by design inspection.

**Relevance:** The design consists of separate modules for frequency measurement (`freq_counter`), duty cycle measurement (`duty_cycle_counter`), and seven-segment display control (`SevenSegmentDecoder`), integrated at the top level. This is confirmed by the project source structure and the testbench instantiation. No simulation test is required for this structural requirement.

## Verification Conclusion

**Overall Verification Status: Pass with Pending Tests**
